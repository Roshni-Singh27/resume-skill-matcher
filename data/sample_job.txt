BACKEND SOFTWARE ENGINEER

--------------------------------------------------
JOB DESCRIPTION
--------------------------------------------------

We are looking for a Backend Software Engineer to
join our engineering team.

The candidate will be responsible for developing,
testing and maintaining scalable backend services
and APIs.

--------------------------------------------------
REQUIRED SKILLS
--------------------------------------------------

The candidate must have experience with:

- Python
- FastAPI
- REST APIs
- PostgreSQL
- Docker
- Git
- Linux
- AWS
- SQL
- Object-Oriented Programming
- Data Structures and Algorithms

--------------------------------------------------
PREFERRED SKILLS
--------------------------------------------------

Experience with the following technologies is preferred:

- Kubernetes
- Redis
- Kafka
- CI/CD
- Jenkins
- Terraform
- Microservices
- GraphQL

--------------------------------------------------
EXPERIENCE REQUIREMENTS
--------------------------------------------------

- 2+ years of professional software development
  experience.
- Experience designing and developing REST APIs.
- Experience working with relational databases.
- Experience deploying applications to cloud platforms.
- Experience working in Linux environments.
- Experience with containerization and Docker.
- Ability to write clean, maintainable and testable code.

--------------------------------------------------
PROJECT EXPERIENCE
--------------------------------------------------

Candidates should demonstrate experience building
at least one backend or distributed-system project.

Projects involving cloud deployment, APIs,
microservices or scalable backend systems will be
highly valued.

--------------------------------------------------
EDUCATION
--------------------------------------------------

Bachelor's degree in Computer Science, Information
Technology, Software Engineering or a related field.

- Design and develop backend services.
- Build and maintain REST APIs.
- Work with PostgreSQL and other databases.
- Deploy services to AWS.
- Containerize applications using Docker.
- Write unit and integration tests.

- Troubleshoot production issues.
- Collaborate with frontend and DevOps teams.
