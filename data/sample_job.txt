## Software Developer Intern

**Company:** TechNova Solutions
**Location:** Noida, India
**Job Type:** Internship / Full-Time Opportunity

### About the Role

We are looking for a motivated Software Developer Intern to join our development team. The candidate will work on web applications, software development, APIs, and data-driven features while collaborating with other developers to build scalable and user-friendly solutions.

### Responsibilities

* Develop and maintain web applications using modern programming languages.
* Write clean, efficient, and maintainable code.
* Build responsive user interfaces using HTML, CSS, and JavaScript.
* Work with REST APIs and integrate third-party services.
* Debug applications and solve technical problems.
* Collaborate with team members using Git and GitHub.
* Work with databases and perform basic data management.
* Participate in code reviews and software testing.
* Explore AI/ML-based solutions for improving software products.
